# Shock UI System Skill

This skill governs the high-contrast editorial and creative agency design system for Hybrid Studioz:
1. **Super Headings (`<SuperHeading />`):**
   - Monumental typography with tight tracking (`-0.04em`), uppercase lockup, `<mark>` gradient text highlight, and animated reveal underlines.

2. **Double-Edge & Outline Cards (`<DoubleEdgeCard />`):**
   - High-contrast layered borders (`1px solid rgba(255,255,255,0.08)` outer with offset subtle inner hairline), glow hover physics, and dark obsidian surface backgrounds.

3. **Magnetic Cards (`<MagneticCard />`):**
   - Interactive 3D cursor-pull and tilt dynamics with custom cursor badge integration (`data-cursor="VIEW CASE"`).

4. **Circular Text Badges (`<CircularText />`):**
   - Continuously rotating SVG circular typography (`"HYBRID STUDIOZ • EST 2026 •"`) with center symbol.

5. **Carousels & Filter Grids:**
   - Swiper-powered touch carousel for editorial insights (`blog-10`).
   - Category filter pill matrix with animated layout transitions (`portfolio-7`).

6. **Direct Modal & Accordions:**
   - Multi-step inquiry drawer (`<DirectModal />`) accessible globally.
   - Smooth height-animated dark collapsible accordion with search filtering (`<DarkAccordion />`).
